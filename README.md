# 📝 Task Manager

A simple and professional **Task Manager desktop application** developed using **C# and Windows Forms**.
The application allows users to create, manage, complete, delete, and refresh tasks through an easy-to-use graphical interface.

---

## 📌 Features

* ➕ Add new tasks
* 📝 Add task descriptions
* 📅 Select task due dates
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 🔄 Refresh task list
* 📊 Display tasks in a DataGridView
* 🎨 Professional and modern user interface
* 🖥️ Windows desktop application
* 🎯 Simple and easy-to-use design

## 🖥️ User Interface

The application contains:

### Task Name

Enter the name of the task.

### Description

Enter additional information about the task.

### Due Date

Select the date by which the task should be completed.

### Add Task

Adds the new task to the task list.

### Complete

Marks the selected task as completed.

### Delete

Deletes the selected task.

### Refresh

Refreshes the task list.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Visual Studio**



## 📋 How to Use

1. Enter a **Task Name**.
2. Enter the **Description**.
3. Select a **Due Date**.
4. Click **Add Task**.
5. Select a task from the table.
6. Click **Complete** to mark it completed.
7. Click **Delete** to remove a task.
8. Click **Refresh** to reload the task list.
